WCAG 2.2 Target Size Example

❌ Bad Example (Fails)

Too small (20×20) and too close → hard to tap.

✅ Good Example (Passes)

Buttons are large and spaced → easy to tap on touch devices.

✅ Pass (Using Spacing via gap)

Small buttons, but large spacing between them → meets WCAG 2.2 Target Size (Minimum).

✅ Pass (Using Spacing via margin)

Buttons are small, but margin creates enough space → avoids accidental taps.
